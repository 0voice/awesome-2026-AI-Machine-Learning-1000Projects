# 手撕：版本号对比（面试高频题）
## 题目描述
给定两个版本号 `version1` 和 `version2`，请比较它们的大小：
- 如果 `version1 > version2`，返回 `1`；
- 如果 `version1 < version2`，返回 `-1`；
- 如果 `version1 == version2`，返回 `0`。

**规则说明**：
1. 版本号由一个或多个数字段组成，段之间用 `.` 分隔（如 `1.0.1`、`2.0`）；
2. 数字段的前导零无意义（如 `1.01` 等价于 `1.1`，`1.000` 等价于 `1`）；
3. 版本号长度可不一致，短版本号末尾补零后比较（如 `1.0` 等价于 `1.0.0`）。

**示例**：
- 输入：`version1 = "1.01", version2 = "1.001"` → 输出 `0`
- 输入：`version1 = "1.0", version2 = "1.0.0"` → 输出 `0`
- 输入：`version1 = "0.1", version2 = "1.1"` → 输出 `-1`
- 输入：`version1 = "1.0.1", version2 = "1.0.0.2"` → 输出 `1`

## 核心思路
1. **分割+转整数**：将版本号按 `.` 分割为字符串列表，转成整数（自动消除前导零）；
2. **补零对齐**：将两个列表补零至相同长度（解决版本号段数不一致问题）；
3. **逐位比较**：遍历每一位数字，按位判断大小，遇到不同位直接返回结果；若所有位相等则返回 `0`。

## 代码实现（Python，最优版）
```python
def compareVersion(version1: str, version2: str) -> int:
    # 步骤1：分割版本号并转整数（消除前导零）
    v1 = [int(num) for num in version1.split('.')]
    v2 = [int(num) for num in version2.split('.')]
    
    # 步骤2：补零对齐长度（取两个列表的最大长度）
    max_len = max(len(v1), len(v2))
    v1 += [0] * (max_len - len(v1))
    v2 += [0] * (max_len - len(v2))
    
    # 步骤3：逐位比较
    for num1, num2 in zip(v1, v2):
        if num1 > num2:
            return 1
        elif num1 < num2:
            return -1
    
    # 所有位相等
    return 0

# 测试用例（覆盖所有核心场景）
if __name__ == "__main__":
    assert compareVersion("1.01", "1.001") == 0    # 前导零
    assert compareVersion("1.0", "1.0.0") == 0     # 长度不一致
    assert compareVersion("0.1", "1.1") == -1      # v1 < v2
    assert compareVersion("1.0.1", "1.0.0.2") == 1 # v1 > v2
    assert compareVersion("1.1", "1.0.9") == 1     # 中间位更大
    assert compareVersion("", "0") == 0            # 空字符串等价于0
    assert compareVersion("2", "1.9999") == 1      # 主版本号更大
    print("所有测试用例通过！")
```

## 关键细节解释（面试必说）
1. **转整数消除前导零**：  
   分割后的字符串（如 `"01"`、`"001"`）转整数后自动变成 `1`，无需手动处理前导零，简洁且高效。
2. **补零对齐的必要性**：  
   版本号段数不同时（如 `1.0` vs `1.0.0`），短版本号末尾补零才能保证比较逻辑正确，避免「`1.0` 比 `1.0.0` 短就判定更小」的错误。
3. **逐位比较的终止条件**：  
   只要某一位数字不同，立即返回结果（无需遍历剩余位），保证最优时间复杂度（$O(n)$，$n$ 为最长版本号的段数）。

## 边界场景处理（面试加分）
- **空字符串**：`""` 等价于 `"0"`，分割后得到空列表，补零后为 `[0]`，与 `"0"` 比较返回 `0`；
- **单段版本号**：`"2"` vs `"1.9999"` → 补零后为 `[2]` vs `[1,9999]` → 第一位 `2>1`，直接返回 `1`；
- **超长版本号**：仅遍历到第一个不同位即终止，无性能问题。

### 总结
1. 核心逻辑：**分割转整数 + 补零对齐 + 逐位比较**，时间/空间复杂度均为 $O(n)$（$n$ 为最长版本号段数）；
2. 关键技巧：利用整数转换自动消除前导零，补零对齐解决段数不一致问题；
3. 边界处理：覆盖空字符串、单段版本号、前导零等所有面试高频场景。
