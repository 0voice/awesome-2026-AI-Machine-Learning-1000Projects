### 题目描述
假设你正在爬楼梯。需要爬 **n** 阶才能到达楼顶。
每次你可以爬 **1** 或 **2** 个台阶。
**问：一共有多少种不同的爬法？**

---

### 方法一：标准动态规划（DP数组版）
#### 1. 思路分析
- **定义状态**：设 `dp[i]` 为爬到第 `i` 阶台阶的方法数。
- **状态转移**：
  要到达第 `i` 阶，最后一步只有两种可能：
  1. 从第 `i-1` 阶爬1级上来 → 方法数是 `dp[i-1]`
  2. 从第 `i-2` 阶爬2级上来 → 方法数是 `dp[i-2]`
  所以：**`dp[i] = dp[i-1] + dp[i-2]`**
- **初始条件**：
  - `dp[1] = 1`（1阶只有1种方法）
  - `dp[2] = 2`（2阶有 1+1, 2 两种方法）

#### 2. 代码实现（Python）
```python
def climbStairs(n: int) -> int:
    # 边界处理
    if n == 1:
        return 1
    # 1. 初始化dp数组
    # dp[0] 占位，dp[1]和dp[2] 是初始值
    dp = [0] * (n + 1)
    dp[1] = 1
    dp[2] = 2
    
    # 2. 从3阶开始递推
    for i in range(3, n + 1):
        dp[i] = dp[i-1] + dp[i-2]
    
    return dp[n]
```

#### 3. 复杂度
- **时间**：O(n) —— 只需要遍历一次。
- **空间**：O(n) —— 使用了长度为 n+1 的数组。

### 方法二：空间优化版（面试加分项）
#### 1. 思路
观察递推公式 `dp[i] = dp[i-1] + dp[i-2]`，我们发现计算第 `i` 项只需要前两项的值，不需要整个数组。
用 **两个变量** 滚动更新，即可把空间复杂度降到 O(1)。

#### 2. 代码实现
```python
def climbStairs_optimized(n: int) -> int:
    if n == 1:
        return 1
    if n == 2:
        return 2
    
    # 初始化：prev_prev 对应 dp[i-2], prev 对应 dp[i-1]
    prev_prev, prev = 1, 2
    
    # 从第3阶迭代到第n阶
    for _ in range(3, n + 1):
        # 当前值 = 前两个值之和
        curr = prev_prev + prev
        # 滚动：前前个 -> 前个，当前个 -> 新的前个
        prev_prev, prev = prev, curr
    
    return prev
```

### 方法三：递归（不推荐，但要会说）
虽然能解决，但**时间复杂度极高 O(2^n)**，存在大量重复计算，面试时提一下思路即可，不要写这个。
```python
def climbStairs_recursive(n: int) -> int:
    if n == 1: return 1
    if n == 2: return 2
    return climbStairs_recursive(n-1) + climbStairs_recursive(n-2)
```

### 💡 面试满分总结
1. **核心公式**：`dp[i] = dp[i-1] + dp[i-2]`（这是斐波那契数列的应用）。
2. **初始条件**：`dp[1]=1`, `dp[2]=2`。
3. **优化技巧**：用两个变量代替数组，空间优化到 O(1)。
4. **应用场景**：这类问题属于**无后效性**动态规划，只要找到递推关系就能解。
