# 力扣 15. 三数之和（手撕最优版）
## 题目描述
给定一个整数数组 `nums`，请你找出所有**和为目标数（通常为 0）** 且**不重复**的三元组 `[nums[i], nums[j], nums[k]]`（要求 $i \neq j \neq k$）。
**示例**：
输入：`nums = [-1,0,1,2,-1,-4]`，目标数 `target = 0`
输出：`[[-1,-1,2],[-1,0,1]]`

### 核心约束
1. 结果中不能包含重复的三元组；
2. 时间复杂度需优化（暴力法 $O(n^3)$ 会超时）。

---

## 核心思路：排序 + 双指针
最优解法是「排序 + 固定首元素 + 双指针」，时间复杂度 $O(n^2)$（排序 $O(n\log n)$ + 双指针遍历 $O(n^2)$），空间复杂度 $O(\log n)$（排序的栈空间）。

### 核心逻辑
1. **排序**：先对数组排序，既方便双指针移动找和，又能快速去重；
2. **固定首元素**：遍历数组，将 `nums[i]` 作为三元组第一个数，剩余两个数用双指针在 `i` 右侧找；
3. **双指针找和**：左指针 `left = i+1`，右指针 `right = len(nums)-1`，根据三数之和与目标数的大小关系移动指针：
   - 和 < 目标数：左指针右移（增大和）；
   - 和 > 目标数：右指针左移（减小和）；
   - 和 = 目标数：记录结果，并跳过重复元素（避免重复三元组）；
4. **去重**：
   - 首元素去重：若 `nums[i] == nums[i-1]`，跳过（避免重复的首元素）；
   - 双指针去重：找到有效组合后，跳过左侧/右侧重复的元素。

---

## 代码实现（Python 最优版）
```python
def threeSum(nums: list[int], target: int = 0) -> list[list[int]]:
    res = []
    n = len(nums)
    # 边界条件：数组长度小于3，直接返回空
    if n < 3:
        return res
    
    # 步骤1：排序（核心前提，方便双指针+去重）
    nums.sort()
    
    # 步骤2：遍历固定第一个数
    for i in range(n):
        # 优化：排序后首元素大于target，三数之和必大于target（正数场景）
        if nums[i] > target and target >= 0:
            break
        
        # 去重：跳过重复的首元素（i>0 避免越界）
        if i > 0 and nums[i] == nums[i-1]:
            continue
        
        # 初始化双指针
        left = i + 1
        right = n - 1
        
        # 步骤3：双指针找另外两个数
        while left < right:
            current_sum = nums[i] + nums[left] + nums[right]
            
            if current_sum == target:
                # 找到有效组合，加入结果
                res.append([nums[i], nums[left], nums[right]])
                
                # 去重：跳过左侧重复元素
                while left < right and nums[left] == nums[left+1]:
                    left += 1
                # 去重：跳过右侧重复元素
                while left < right and nums[right] == nums[right-1]:
                    right -= 1
                
                # 移动指针，继续找下一组
                left += 1
                right -= 1
            
            elif current_sum < target:
                # 和太小，左指针右移增大和
                left += 1
            else:
                # 和太大，右指针左移减小和
                right -= 1
    
    return res

# 测试用例
if __name__ == "__main__":
    assert threeSum([-1,0,1,2,-1,-4]) == [[-1,-1,2],[-1,0,1]]
    assert threeSum([]) == []
    assert threeSum([0]) == []
    assert threeSum([0,0,0]) == [[0,0,0]]
    assert threeSum([1,2,-2,-1], 0) == []
    print("所有测试用例通过！")
```

## 关键细节解释（面试必说）
### 1. 为什么先排序？
- 排序后能通过「跳过相邻重复元素」快速去重，避免结果中有重复三元组；
- 排序后双指针可通过单向移动调整和的大小，无需暴力枚举所有组合。

### 2. 首元素优化的意义？
若排序后 `nums[i] > target` 且 `target ≥ 0`（如 target=0，nums[i]=1），则 `nums[i] + nums[left] + nums[right] ≥ nums[i] > 0`，不可能等于target，直接break，减少无效遍历。

### 3. 去重的时机？
- 首元素去重：必须在 `i>0` 时判断（避免 `i=0` 时和 `i-1=-1` 越界）；
- 双指针去重：必须在「找到有效组合后」执行，且要保证 `left < right`（避免指针交叉）。

### 4. 时间/空间复杂度
- 时间：$O(n^2)$（排序 $O(n\log n)$ + 双指针遍历 $O(n^2)$，主导项为 $O(n^2)$）；
- 空间：$O(\log n)$（排序的栈空间，若允许修改原数组，无额外空间；若要求不修改，需 $O(n)$ 空间拷贝数组）。

## 对比暴力法（面试避坑）
暴力法通过三层循环枚举所有三元组，时间复杂度 $O(n^3)$，且需额外去重，力扣会超时，仅作反面教材：
```python
def threeSum_brute(nums: list[int], target: int = 0) -> list[list[int]]:
    res = set()  # 用集合去重
    n = len(nums)
    for i in range(n):
        for j in range(i+1, n):
            for k in range(j+1, n):
                if nums[i] + nums[j] + nums[k] == target:
                    # 排序后加入集合，避免重复
                    res.add(tuple(sorted([nums[i], nums[j], nums[k]])))
    return [list(x) for x in res]
```

---

## 总结
1. **核心解法**：排序 + 固定首元素 + 双指针，时间 $O(n^2)$ 是该题最优解；
2. **关键技巧**：排序是前提，去重是核心（首元素+双指针双维度去重）；
3. **边界处理**：先判断数组长度 <3 的情况，首元素过大时直接break，提升效率。
