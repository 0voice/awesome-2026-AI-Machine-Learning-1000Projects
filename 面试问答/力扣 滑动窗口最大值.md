# 力扣 239. 滑动窗口最大值（手撕最优版）
## 题目描述
给定一个整数数组 `nums` 和一个整数 `k`，请你找出所有长度为 `k` 的滑动窗口里的最大值，返回这些最大值组成的数组。
**示例**：
输入：`nums = [1,3,-1,-3,5,3,6,7], k = 3`
输出：`[3,3,5,5,6,7]`
解释：
```
滑动窗口位置                最大值
---------------               -----
[1  3  -1] -3  5  3  6  7       3
 1 [3  -1  -3] 5  3  6  7       3
 1  3 [-1  -3  5] 3  6  7       5
 1  3  -1 [-3  5  3] 6  7       5
 1  3  -1  -3 [5  3  6] 7       6
 1  3  -1  -3  5 [3  6  7]      7
```

## 核心思路：单调队列（双端队列）
暴力法（遍历每个窗口找最大值）时间复杂度 $O(nk)$，会超时；最优解法是**单调递减双端队列**，时间复杂度 $O(n)$（每个元素入队/出队各一次）。

### 核心逻辑
1. **队列存储索引**：不存值，而是存元素的索引，方便判断元素是否超出窗口范围；
2. **维护队列单调递减**：队列头部始终是当前窗口的最大值索引，队尾依次是次大值、第三大值…；
3. **窗口滑动时的操作**：
   - 移除「超出窗口左边界」的索引（队列头部索引 ≤ 当前索引 - k）；
   - 移除「队尾比当前元素小」的索引（这些元素不可能成为后续窗口的最大值）；
   - 加入当前索引，收集窗口最大值（仅当窗口形成时）。

## 代码实现（Python 最优版）
```python
from collections import deque

def maxSlidingWindow(nums: list[int], k: int) -> list[int]:
    # 初始化双端队列（存索引）、结果列表
    q = deque()
    res = []
    
    for i in range(len(nums)):
        # 1. 移除超出窗口左边界的索引（窗口左边界是 i - k + 1，索引 < 左边界则弹出）
        while q and q[0] <= i - k:
            q.popleft()
        
        # 2. 维护队列单调递减：从队尾移除所有比当前元素小的索引
        while q and nums[i] > nums[q[-1]]:
            q.pop()
        
        # 3. 加入当前元素的索引
        q.append(i)
        
        # 4. 窗口形成（i >= k-1）时，收集队列头部的最大值
        if i >= k - 1:
            res.append(nums[q[0]])
    
    return res

# 测试用例
if __name__ == "__main__":
    assert maxSlidingWindow([1,3,-1,-3,5,3,6,7], 3) == [3,3,5,5,6,7]
    assert maxSlidingWindow([1], 1) == [1]
    assert maxSlidingWindow([1,-1], 1) == [1,-1]
    assert maxSlidingWindow([9,11], 2) == [11]
    assert maxSlidingWindow([4,-2], 2) == [4]
    print("所有测试用例通过！")
```

## 关键细节解释（面试必说）
### 1. 为什么存索引而不是值？
比如窗口滑动后，需要判断队列头部的最大值是否还在当前窗口内（索引 ≤ i - k 则超出），存值无法判断位置，存索引是核心技巧。

### 2. 为什么要维护单调递减队列？
假设当前元素是 `5`，队尾有 `-3`、`-1` 的索引：
- `-3` 和 `-1` 比 `5` 小，且在 `5` 的左侧；
- 后续窗口只要包含 `5`，`-3`、`-1` 就不可能成为最大值，因此可以直接移除，减少无效判断。

### 3. 时间复杂度为什么是 O(n)？
每个元素最多被加入队列一次、弹出队列一次，总操作次数是 $2n$，因此时间复杂度是 $O(n)$；空间复杂度是 $O(k)$（队列最多存储 k 个元素）。

## 备选解法（暴力法，仅作对比，面试不推荐）
```python
def maxSlidingWindow_brute(nums: list[int], k: int) -> list[int]:
    res = []
    for i in range(len(nums) - k + 1):
        window = nums[i:i+k]
        res.append(max(window))
    return res
```
- 时间复杂度：$O(nk)$（n 是数组长度，k 是窗口大小），当 k 接近 n 时，复杂度退化为 $O(n^2)$，力扣会超时。

## 总结
1. **核心解法**：单调递减双端队列，时间 $O(n)$、空间 $O(k)$，是该题的最优解；
2. **关键技巧**：队列存索引（判断窗口范围）+ 维护单调递减（保证头部是最大值）；
3. **窗口形成条件**：遍历到 $i \geq k-1$ 时才开始收集结果，避免提前取到不完整窗口的最大值。
