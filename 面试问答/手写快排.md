### 手写快速排序（Python ）
**思路**：随机基准 + 双指针分区 + 分治递归，原地排序，平均复杂度 \(O(n\log n)\)

```python
def quick_sort(nums, left=None, right=None):
    # 初始化左右边界
    if left is None:
        left = 0
    if right is None:
        right = len(nums) - 1
    
    # 递归终止条件
    if left >= right:
        return
    
    # 随机选基准（避免有序数组退化为 O(n²)）
    pivot_idx = random.randint(left, right)
    nums[pivot_idx], nums[right] = nums[right], nums[pivot_idx]
    
    # 分区：返回基准最终位置
    pivot_pos = partition(nums, left, right)
    
    # 递归左右子数组
    quick_sort(nums, left, pivot_pos - 1)
    quick_sort(nums, pivot_pos + 1, right)

def partition(nums, left, right):
    pivot = nums[right]  # 基准值
    i = left - 1         # 小于基准区域的右边界
    
    # 遍历区间，将小于基准的数放到左侧
    for j in range(left, right):
        if nums[j] <= pivot:
            i += 1
            nums[i], nums[j] = nums[j], nums[i]
    
    # 把基准放到最终位置
    nums[i + 1], nums[right] = nums[right], nums[i + 1]
    return i + 1
```

### 极简调用版（面试可直接写）
```python
import random

def quick_sort(nums):
    if len(nums) <= 1:
        return nums
    pivot = random.choice(nums)
    left = [x for x in nums if x < pivot]
    mid = [x for x in nums if x == pivot]
    right = [x for x in nums if x > pivot]
    return quick_sort(left) + mid + quick_sort(right)
```

---

### 核心要点（面试口述）
1. **分治思想**：选基准 → 分区 → 递归子数组
2. **分区逻辑**：小于基准放左，大于放右，基准归位
3. **随机基准**：规避有序数组的最坏时间复杂度 \(O(n^2)\)
4. **复杂度**：平均 \(O(n\log n)\)，最坏 \(O(n^2)\)，空间 \(O(\log n)\)（递归栈）
