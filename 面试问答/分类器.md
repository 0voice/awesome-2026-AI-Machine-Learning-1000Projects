# 用输出概率1/2的分类器构造1/7概率分类器
## 核心原理
本质是**利用“独立重复试验+等概率结果筛选”**：  
1/2概率的分类器（可视为“公平硬币”），通过**多次独立调用**生成等概率的结果集合，再通过“排除无效结果+重新试验”的规则，将目标事件的概率收敛到1/7。

### 关键前提
设原分类器为 $C$，输出正例（记为1）和反例（记为0）的概率均为1/2，且每次调用**独立同分布**（i.i.d）。

---

## 一、构造步骤（面试可口述+手撕）
### 步骤1：确定试验次数
要构造1/7的概率，需找到最小的 $n$ 使得 $2^n > 7$ → $n=3$（因为 $2^3=8$，8个等概率结果，可覆盖7个有效结果）。  
调用3次原分类器，得到一个3位二进制序列（如000、001、…、111），共8种结果，每种结果的概率为 $(1/2)^3 = 1/8$。

### 步骤2：定义有效/无效结果
- **有效结果**：前7种序列（000、001、010、011、100、101、110），共7种；
- **无效结果**：最后1种序列（111），共1种。

### 步骤3：制定输出规则
1. 连续调用3次原分类器，得到二进制序列 $S$；
2. 若 $S$ 是**无效结果（111）**：放弃本次结果，重新执行步骤1（重新试验）；
3. 若 $S$ 是**有效结果**：
   - 仅当 $S=000$ 时，新分类器输出正例（概率1/7）；
   - 其余6种有效结果时，输出反例（概率6/7）。

### 步骤4：概率验证（面试必算）
设新分类器输出正例的概率为 $P$，则：
$$
P = \underbrace{\frac{7}{8} \times \frac{1}{7}}_{\text{有效结果且命中000}} + \underbrace{\frac{1}{8} \times P}_{\text{无效结果，重新试验}}
$$
解方程：
$$
P = \frac{1}{8} + \frac{P}{8} \implies 8P = 1 + P \implies P = \frac{1}{7}
$$

## 二、代码实现（Python，可直接运行）
```python
import random

# 原分类器：输出0/1的概率均为1/2
def base_classifier():
    # random.randint(0,1) 等价于公平硬币，0/1概率各1/2
    return random.randint(0, 1)

# 构造的1/7概率分类器
def seven_classifier():
    while True:
        # 步骤1：调用3次原分类器，生成3位二进制序列
        s1 = base_classifier()
        s2 = base_classifier()
        s3 = base_classifier()
        seq = (s1, s2, s3)
        
        # 步骤2：判断是否为无效结果（111）
        if seq == (1, 1, 1):
            continue  # 重新试验
        
        # 步骤3：有效结果，判断是否输出正例
        if seq == (0, 0, 0):
            return 1  # 正例，概率1/7
        else:
            return 0  # 反例，概率6/7

# 验证：统计10000次试验的正例频率（接近1/7≈0.1429）
if __name__ == "__main__":
    total = 100000
    positive = 0
    for _ in range(total):
        if seven_classifier() == 1:
            positive += 1
    print(f"正例频率：{positive/total:.4f}（理论值：1/7≈0.1429）")
```

### 输出示例
```
正例频率：0.1431（理论值：1/7≈0.1429）
```

## 三、核心扩展（面试加分）
### 1. 通用化：构造1/k概率的分类器
只要 $k$ 是正整数，均可通过此方法构造：
- 找最小的 $n$ 使得 $2^n \geq k$；
- 取前 $k$ 种结果为有效结果，其余为无效结果；
- 仅1种有效结果输出正例，其余输出反例，无效结果重新试验。

### 2. 效率优化
上述方法可能因“重新试验”产生额外开销，可通过**扩大结果集**减少重试验概率（如用4次试验生成16种结果，取前7种有效，重试验概率从1/8降到9/16？不，4次试验是16种，取7种有效，重试验概率9/16，反而更高，因此3次是最优的）。

### 3. 工程落地注意事项
- 原分类器必须满足“独立同分布”：若原分类器存在状态依赖（如前后调用结果相关），需先解耦；
- 重试验的终止条件：实际工程中需设置最大重试次数（如10次），避免无限循环（概率极低，10次重试失败概率为 $(1/8)^{10} ≈ 9.5e-10$）。

## 总结
1. **核心逻辑**：用3次独立的1/2概率试验生成8种等概率结果，排除1种无效结果后，剩余7种结果等概率（1/7）；
2. **关键验证**：通过条件概率方程证明最终输出正例的概率为1/7；
3. **通用扩展**：此方法可构造任意1/k（k为正整数）的概率分类器，核心是“等概率结果集+无效结果重试验”。
