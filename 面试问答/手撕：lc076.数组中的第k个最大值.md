# 修正说明：力扣215. 数组中的第K个最大元素
## 题目描述
给定整数数组 `nums` 和整数 `k`，请返回数组中**第 k 个最大**的元素。
- 要求：时间复杂度尽可能优于 $O(n\log n)$，k 从 1 开始计数（如数组 `[3,2,1,5,6,4]`，k=2 时返回 5）。

## 核心思路：快速选择（QuickSelect）
这是该题的**最优解法**，基于快速排序的「分区思想」，无需全排序，仅定向查找目标位置，平均时间复杂度 $O(n)$（最坏 $O(n^2)$，随机选基准可规避），空间复杂度 $O(\log n)$（递归栈）。

### 核心逻辑
1. **分区（Partition）**：选基准值，将数组按「降序」分为「左（>基准）、中（基准）、右（<基准）」；
2. **定向递归**：
   - 若基准索引 = k-1（第k大对应索引k-1），直接返回基准；
   - 若基准索引 < k-1，目标在右侧，递归右侧；
   - 若基准索引 > k-1，目标在左侧，递归左侧；
3. **关键优化**：随机选基准，避免有序数组导致的最坏时间复杂度。

## 代码实现（Python 可直接运行，最优版）
```python
import random

def findKthLargest(nums: list[int], k: int) -> int:
    def quick_select(left: int, right: int) -> int:
        # 递归终止：区间仅一个元素，直接返回
        if left == right:
            return nums[left]
        
        # 优化1：随机选基准（避免有序数组退化为O(n²)）
        pivot_idx = random.randint(left, right)
        # 将基准交换到区间最右侧（适配分区逻辑）
        nums[pivot_idx], nums[right] = nums[right], nums[pivot_idx]
        
        # 分区：降序排列，返回基准最终位置
        pivot_pos = partition(left, right)
        
        # 定向递归：找第k大（对应索引k-1）
        if pivot_pos == k - 1:
            return nums[pivot_pos]
        elif pivot_pos < k - 1:
            # 目标在右侧，递归右侧区间
            return quick_select(pivot_pos + 1, right)
        else:
            # 目标在左侧，递归左侧区间
            return quick_select(left, pivot_pos - 1)
    
    def partition(left: int, right: int) -> int:
        """降序分区：返回基准的最终索引"""
        pivot = nums[right]  # 基准值（区间最右侧）
        i = left - 1         # 大于基准区域的右边界
        
        # 遍历[left, right-1]，把大于基准的元素放到左侧
        for j in range(left, right):
            if nums[j] >= pivot:
                i += 1
                nums[i], nums[j] = nums[j], nums[i]
        
        # 把基准放到最终位置（i+1）
        nums[i+1], nums[right] = nums[right], nums[i+1]
        return i + 1
    
    # 调用快速选择，初始区间为整个数组
    return quick_select(0, len(nums)-1)

# 测试用例（覆盖常规/边界场景）
if __name__ == "__main__":
    assert findKthLargest([3,2,1,5,6,4], 2) == 5  # 常规场景
    assert findKthLargest([3,2,3,1,2,4,5,5,6], 4) == 4  # 重复元素
    assert findKthLargest([1], 1) == 1  # 单元素
    assert findKthLargest([5,2,4,1,3,6,0], 4) == 3  # 乱序
    print("所有测试用例通过！")
```

## 关键细节解释（面试必说）
1. **为什么随机选基准？**
   若数组有序（如 `[1,2,3,4,5]`），固定选最右侧为基准会导致分区后一侧为空，时间复杂度退化为 $O(n^2)$；随机选基准可将最坏情况的概率降到极低。

2. **分区为什么用降序？**
   第k大的元素对应索引 `k-1`，降序分区后，基准位置可直接匹配「第几大」，逻辑更直观（若用升序，需转换为「第 n-k+1 小」）。

3. **时间/空间复杂度**：
   - 平均时间：$O(n)$（每个元素最多入/出分区一次）；
   - 最坏时间：$O(n^2)$（极端随机情况）；
   - 空间：$O(\log n)$（递归栈深度，平均为对数级）。

## 备选解法（对比学习）
### 解法1：排序法（简单但效率低）
```python
def findKthLargest_sort(nums: list[int], k: int) -> int:
    nums.sort(reverse=True)
    return nums[k-1]
```
- 时间：$O(n\log n)$（排序耗时），适合小数据量快速验证。

### 解法2：小顶堆法（适合大数据/流式数据）
```python
import heapq

def findKthLargest_heap(nums: list[int], k: int) -> int:
    heap = []
    for num in nums:
        heapq.heappush(heap, num)
        if len(heap) > k:  # 维护堆大小为k，堆顶是第k大
            heapq.heappop(heap)
    return heap[0]
```
- 时间：$O(n\log k)$（遍历n个元素，堆操作 $O(\log k)$）；
- 空间：$O(k)$，适合内存有限的大数据场景。

## 总结
1. **核心解法**：快速选择（QuickSelect），平均时间 $O(n)$ 是该题最优解，核心是「分区+定向递归」；
2. **关键优化**：随机选基准规避最坏时间复杂度，降序分区简化索引匹配；
3. **选型原则**：小数据用排序，大数据用堆，常规场景优先快速选择。
