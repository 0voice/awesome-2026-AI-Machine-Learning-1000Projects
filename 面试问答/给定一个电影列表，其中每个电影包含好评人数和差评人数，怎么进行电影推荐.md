# 电影推荐（基于好评/差评人数）全流程方案
核心逻辑：**不能直接用「好评数」或「好评率」推荐**（小样本偏差致命），需先通过「统计修正」得到「可信度评分」，再结合业务规则/用户偏好做推荐。

---

## 一、核心问题：为什么不能直接用好评数/好评率？
举个反例：
- 电影A：1条评价，1个好评 → 好评率100%
- 电影B：1000条评价，900个好评 → 好评率90%
直接按好评率排序会优先推荐A，但A的评分完全不可信；按好评数排序会只推爆款，忽略小众优质电影。

→ 必须用「**兼顾评分高低+评价样本量**」的修正指标，解决小样本偏差。

---

## 二、第一步：计算「可信度评分」（核心）
### 1. 首选：威尔逊得分（Wilson Score，最常用）
#### 原理
对二分类（好评/差评）数据，计算「真实好评率的95%置信区间下限」，既考虑好评率，又惩罚样本量少的电影，是电商/内容平台的标准方案。

#### 公式（简化版，95%置信度）
$$
\text{Wilson Score} = \frac{\hat{p} + \frac{z^2}{2n} - z\sqrt{\frac{\hat{p}(1-\hat{p})}{n} + \frac{z^2}{4n^2}}}{1 + \frac{z^2}{n}}
$$
- $\hat{p}$：好评率 = 好评数/(好评数+差评数)；
- $n$：总评价数 = 好评数+差评数；
- $z$：95%置信度对应的z值（固定为1.96）。

#### 代码实现（Python）
```python
import math

def wilson_score(positive: int, negative: int, z: float = 1.96) -> float:
    """
    计算威尔逊得分（95%置信区间下限）
    :param positive: 好评数
    :param negative: 差评数
    :param z: 置信度z值（95%→1.96）
    :return: 威尔逊得分（0~1）
    """
    n = positive + negative
    # 无评价时得分设为0
    if n == 0:
        return 0.0
    # 好评率
    p_hat = positive / n
    # 威尔逊得分公式
    denominator = 1 + z**2 / n
    numerator = p_hat + z**2 / (2 * n) - z * math.sqrt((p_hat * (1 - p_hat) + z**2 / (4 * n)) / n)
    score = numerator / denominator
    return score

# 测试：对比反例中的电影A和B
print(wilson_score(1, 0))   # 电影A得分≈0.025（极低）
print(wilson_score(900, 100))# 电影B得分≈0.88（高）
```

### 2. 备选：贝叶斯平均（Bayesian Average）
#### 原理
用「全局平均评分」作为先验，对样本量少的电影，评分向全局平均靠拢，适合有大量电影的场景。

#### 公式
$$
\text{Bayesian Score} = \frac{C \times m + positive}{C + n}
$$
- $C$：校准系数（通常取所有电影的平均评价数，或设固定值如100）；
- $m$：全局平均好评率 = 总好评数/总评价数；
- $positive$：单部电影好评数；
- $n$：单部电影总评价数。

#### 代码实现
```python
def bayesian_average(positive: int, negative: int, global_avg: float, C: int = 100) -> float:
    """
    计算贝叶斯平均得分
    :param positive: 好评数
    :param negative: 差评数
    :param global_avg: 全局平均好评率
    :param C: 校准系数（推荐100）
    :return: 贝叶斯得分（0~1）
    """
    n = positive + negative
    score = (C * global_avg + positive) / (C + n)
    return score

# 测试：假设全局平均好评率0.8，C=100
global_avg = 0.8
print(bayesian_average(1, 0, global_avg))   # 电影A得分≈0.802（向全局平均靠拢）
print(bayesian_average(900, 100, global_avg))# 电影B得分≈0.892（接近自身好评率）
```

## 三、第二步：分场景的推荐策略
### 1. 基础版：无个性化推荐（冷启动/全局推荐）
适合首页「热门优质电影」「高分电影榜」，核心是「修正评分排序+业务规则过滤」：
#### 步骤
1. **过滤低质量电影**：设置「最低评价数门槛」（如n≥50），过滤无评价/极少评价的电影；
2. **计算修正评分**：对剩余电影计算威尔逊得分（首选）；
3. **排序推荐**：按威尔逊得分降序排列，取前N部推荐；
4. **可选加权**：结合「近期评价数」（如近7天评价数占比），给新热电影加权重（避免只推老电影）。

#### 代码示例（全局推荐）
```python
# 电影数据：[(电影名, 好评数, 差评数), ...]
movies = [
    ("电影A", 1, 0),
    ("电影B", 900, 100),
    ("电影C", 500, 50),
    ("电影D", 0, 0),
    ("电影E", 40, 10)
]

# 步骤1：过滤（总评价数≥50）
min_ratings = 50
filtered_movies = [m for m in movies if (m[1]+m[2]) >= min_ratings]

# 步骤2：计算威尔逊得分并排序
movies_with_score = []
for name, pos, neg in filtered_movies:
    score = wilson_score(pos, neg)
    movies_with_score.append((name, score))

# 步骤3：按得分降序排序
movies_with_score.sort(key=lambda x: x[1], reverse=True)

# 输出推荐结果
print("全局高分电影推荐：")
for i, (name, score) in enumerate(movies_with_score, 1):
    print(f"{i}. {name}（威尔逊得分：{score:.3f}）")

# 输出结果：
# 1. 电影B（威尔逊得分：0.880）
# 2. 电影C（威尔逊得分：0.890？实际计算：500/550≈0.909，威尔逊得分≈0.885，比B高）
```

### 2. 进阶版：个性化推荐（核心）
基于「用户偏好+修正评分」，让推荐更精准：
#### 步骤
1. **用户偏好建模**：
   - 若有用户观影/评分数据：计算用户对「类型/导演/演员」的偏好得分（如用户给悬疑片的平均评分0.9，喜剧片0.7）；
   - 若无用户数据（冷启动）：用用户人口属性/浏览行为（如点击过悬疑片）替代；
2. **电影匹配得分**：
   单部电影的最终得分 = 威尔逊得分 × 用户对该电影类型的偏好权重；
3. **排序推荐**：按最终得分降序，结合多样性（如避免推荐同一类型的5部电影）。

#### 代码示例（个性化推荐）
```python
# 假设用户偏好：悬疑片权重1.0，喜剧片0.7，动作片0.9
user_preference = {"悬疑": 1.0, "喜剧": 0.7, "动作": 0.9}

# 电影数据（新增类型）：[(电影名, 好评数, 差评数, 类型), ...]
movies_with_type = [
    ("电影B", 900, 100, "悬疑"),
    ("电影C", 500, 50, "喜剧"),
    ("电影F", 800, 100, "动作")
]

# 计算个性化得分
personalized_movies = []
for name, pos, neg, genre in movies_with_type:
    # 威尔逊得分
    wilson = wilson_score(pos, neg)
    # 偏好权重（无偏好的类型默认0.5）
    weight = user_preference.get(genre, 0.5)
    # 个性化最终得分
    final_score = wilson * weight
    personalized_movies.append((name, final_score))

# 排序推荐
personalized_movies.sort(key=lambda x: x[1], reverse=True)
print("\n个性化推荐：")
for i, (name, score) in enumerate(personalized_movies, 1):
    print(f"{i}. {name}（个性化得分：{score:.3f}）")
```

### 3. 新电影冷启动推荐
新电影无/极少评价（n<50），无法计算修正评分：
1. **初期**：基于「相似电影」推荐（如同一导演/演员的高评分电影）；
2. **中期**：当评价数达到门槛（如20），用贝叶斯平均（向全局平均靠拢）；
3. **后期**：评价数≥50，切换为威尔逊得分。

---

## 四、落地注意事项（面试加分）
1. **评价数门槛**：根据业务调整（如小众平台C=20，大众平台C=100）；
2. **实时更新**：评分需按时间窗口更新（如近30天的好评/差评，避免老评分过时）；
3. **反作弊**：过滤刷好评/差评的异常数据（如同一IP短时间大量评价）；
4. **多样性**：推荐列表中控制同一类型/导演的占比（如≤60%），提升用户体验。

---

## 总结
1. **核心基础**：用「威尔逊得分」修正好评率，解决小样本偏差，是推荐的核心指标；
2. **推荐策略**：无个性化用「修正评分+评价数过滤」，个性化加「用户偏好权重」；
3. **冷启动**：新电影用相似性推荐，评价数达标后切换为修正评分。
