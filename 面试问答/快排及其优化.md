## 一、快排核心原理
**一句话核心**：分治思想 + 分区操作，通过选「基准值」将数组划分为「左≤基准、右≥基准」两部分，递归处理左右子数组，直到子数组长度≤1。

### 核心步骤
1. **选基准（pivot）**：随机/固定选一个元素（如第一个/最后一个）。
2. **分区（partition）**：遍历数组，把≤基准的放左边，≥基准的放右边，返回基准最终位置。
3. **递归**：对基准左右的子数组重复1、2步。

---

## 二、标准快排实现（Python，Lomuto分区法）
Lomuto分区（简单易写，面试优先选）：
```python
def quick_sort(arr, low, high):
    # 递归终止条件：子数组长度≤1
    if low >= high:
        return
    
    # 1. 分区：返回基准最终位置
    pivot_idx = partition(arr, low, high)
    
    # 2. 递归处理左右子数组
    quick_sort(arr, low, pivot_idx - 1)
    quick_sort(arr, pivot_idx + 1, high)

def partition(arr, low, high):
    # 选最后一个元素作为基准
    pivot = arr[high]
    # i：小于基准区域的右边界
    i = low - 1
    
    # 遍历[low, high-1]，把≤pivot的元素放到左边
    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    
    # 把基准放到最终位置（i+1）
    arr[i+1], arr[high] = arr[high], arr[i+1]
    return i + 1

# 测试
if __name__ == "__main__":
    arr = [3, 1, 4, 1, 5, 9, 2, 6]
    quick_sort(arr, 0, len(arr)-1)
    print(arr)  # [1, 1, 2, 3, 4, 5, 6, 9]
```

### 复杂度（标准版）
- **平均时间**：$O(n\log n)$（分区均衡，递归深度$\log n$）。
- **最坏时间**：$O(n^2)$（数组有序/逆序，基准选边界，递归深度$n$）。
- **空间**：$O(\log n)$（递归栈空间，最坏$O(n)$）。

## 三、快排的核心问题（为什么需要优化）
1. 基准选边界 → 有序数组退化成$O(n^2)$。
2. 递归深度过大 → 栈溢出（尤其大数据量）。
3. 重复元素多 → 分区不均（大量元素等于基准，左右子数组失衡）。
4. 小区间递归 → 递归调用开销大于排序本身（插入排序在小数据量下更快）。

---

## 四、快排核心优化方法（面试必背+手撕优化版）
### 优化1：基准选择优化（解决最坏时间复杂度）
- **三数取中法**：选「左、中、右」三个位置的中位数作为基准，避免有序数组坑。
- **随机基准**：随机选基准，概率上避免最坏情况（实现更简单）。

### 优化2：小区间优化（减少递归开销）
当子数组长度≤阈值（如10），改用**插入排序**（插入排序在小数据量下常数项更小，效率更高）。

### 优化3：重复元素优化（三路快排）
将数组划分为「<基准、=基准、>基准」三部分，避免重复元素导致的分区不均。

### 优化4：递归优化（可选）
- 尾递归优化：把递归深度从$n$降到$\log n$。
- 非递归实现：用栈模拟递归，避免栈溢出。

## 五、优化版快排（整合核心优化）
```python
import random

def quick_sort_optimized(arr, low, high):
    # 优化2：小区间改用插入排序（阈值选10）
    if high - low + 1 <= 10:
        insertion_sort(arr, low, high)
        return
    
    # 优化1：三数取中法选基准
    pivot_idx = median_of_three(arr, low, high)
    # 把基准换到最后（适配原partition逻辑）
    arr[pivot_idx], arr[high] = arr[high], arr[pivot_idx]
    
    # 优化3：三路快排（处理重复元素）
    lt, gt = three_way_partition(arr, low, high)
    
    # 递归处理<基准和>基准的区间（=基准的不用处理）
    quick_sort_optimized(arr, low, lt - 1)
    quick_sort_optimized(arr, gt + 1, high)

# 辅助1：三数取中法（选左、中、右的中位数）
def median_of_three(arr, low, high):
    mid = (low + high) // 2
    # 排序左、中、右，返回中位数位置
    if arr[low] > arr[mid]:
        arr[low], arr[mid] = arr[mid], arr[low]
    if arr[low] > arr[high]:
        arr[low], arr[high] = arr[high], arr[low]
    if arr[mid] > arr[high]:
        arr[mid], arr[high] = arr[high], arr[mid]
    return mid

# 辅助2：插入排序（小区间用）
def insertion_sort(arr, low, high):
    for i in range(low + 1, high + 1):
        key = arr[i]
        j = i - 1
        while j >= low and arr[j] > key:
            arr[j + 1] = arr[j]
            j -= 1
        arr[j + 1] = key

# 辅助3：三路快排分区（返回<基准和>基准的边界）
def three_way_partition(arr, low, high):
    pivot = arr[high]
    lt = low - 1  # <基准的右边界
    gt = high     # >基准的左边界
    i = low       # 当前遍历指针
    
    while i < gt:
        if arr[i] < pivot:
            lt += 1
            arr[lt], arr[i] = arr[i], arr[lt]
            i += 1
        elif arr[i] > pivot:
            gt -= 1
            arr[i], arr[gt] = arr[gt], arr[i]
        else:
            i += 1
    
    # 把基准放到=基准区域的最后（gt位置）
    arr[gt], arr[high] = arr[high], arr[gt]
    return lt, gt  # <基准的右边界，>基准的左边界

# 测试
if __name__ == "__main__":
    arr = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]
    quick_sort_optimized(arr, 0, len(arr)-1)
    print(arr)  # [1, 1, 2, 3, 3, 4, 5, 5, 5, 6, 9]
```

## 六、面试满分总结
1. **快排核心**：分治+分区，基准是关键，平均$O(n\log n)$、最坏$O(n^2)$。
2. **核心优化**：
   - 基准：三数取中/随机（避免最坏情况）；
   - 小区间：插入排序（减少递归开销）；
   - 重复元素：三路快排（分区更均衡）。
3. **适用场景**：大数据量、无/少重复元素（优化后可处理重复元素），是工业界最常用的排序算法。
